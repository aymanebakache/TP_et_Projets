# Application Kanban (Vue 3 + Firebase)

Projet réalisé avec Vue.js 3, Pinia et Firebase.
Démo en ligne : https://kanban-5e23b.web.app/

## Comment lancer le projet

1. **Installer les dépendances :**
   ```bash
   npm install
   ```

2. **Lancer en local :**
   ```bash
   npm run dev
   ```

3. **Build pour production (optionnel) :**
   ```bash
   npm run build
   ```
